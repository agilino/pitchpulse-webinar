# 00 · Setup (before the webinar)

Nothing is typed live in this phase. This is the checklist for the state at tag `00-start`.

- Fresh clone of this repo at tag `00-start`, `node_modules` installed for `slides/`.
- Claude Code open in the repo, the plugin `cloudflare@cloudflare` installed, `wrangler login` and `cf auth login` done.
- Finished PitchPulse deployed under a backup URL (see "Operate PitchPulse" in `README.md`), QR code ready.
- draw.io MCP connected and tested with the inception canvas template.
- One sketch photo from a sign-up saved as `docs/sketch.jpg`; a fallback sketch of your own as `docs/sketch-fallback.jpg`.
